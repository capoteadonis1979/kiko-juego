# Guarda Contactos (Marisol)

App Android para guardar números y contactos hablando, pensada para usarla manejando.

- Al colgar una llamada de un número sin nombre, pregunta por voz si lo guarda.
- Se la llama diciendo «Marisol», «mi secretaria» o «mi asistente» (motor de voz dentro de la app, sin internet).
- Con una clave de Gemini entiende lo que se le pida: revisar las últimas llamadas, buscar y guardar contactos.

Cada `push` a la rama `marisol` compila el APK sin firmar con GitHub Actions. El APK firmado para instalar está en la release `marisol`.
